# GROUP 6: THE COUNTERFACTUAL DENOMINATOR

Every metric the bundle emits carries a second number the writer did not choose.
This is a required ORG binding. A business with no external market still has a
moving baseline; the binding forces it to name what its ground is.

TAXONOMY SHAPE, COUNTERFACTUAL_LADDER. A fixed ordered set of six rungs, best
first. The rungs themselves are not configurable; which rungs a business has
available, and which one each metric uses, are.

- Rung 1 SHARE_OF_ADDRESSABLE: share of a bounded addressable population.
- Rung 2 MATCHED_CONTROL: an untouched, unassigned or later-treated segment
  inside the same business.
- Rung 3 PEER_DISTRIBUTION: the distribution of sibling units at the peer level.
- Rung 4 PLAN_ATTAINMENT: percent of a target set before the period by someone
  other than the writer.
- Rung 5 OWN_PRIOR_RUN_RATE: the writer's own prior-period run rate.
- Rung 6 BARE_DENOMINATOR: a population count that bounds the magnitude. The
  floor. No number ever ships alone.
